
# IT Tools 

### Original repo:
https://github.com/CorentinTh/it-tools
 
### Run (docker)

`docker run -d --name it-tools --restart unless-stopped -p 8080:80 corentinth/it-tools:latest`

### Docker-compose (start)

`docker-compose up -d it_tools`

### Docker-compose (stop)
`docker-compose down`

### Web UI:
http://localhost:8080/
